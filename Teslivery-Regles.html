Règles de confidentialité - Dernière mise à jour : 1er novembre 2026

🔒 Résumé : Teslivery ne collecte aucune donnée personnelle. Toutes les données sont stockées localement sur votre appareil.

1. Introduction

Bienvenue dans Teslivery, l'application d'inspection et de réception de véhicules Tesla. Cette politique de confidentialité décrit comment nous traitons vos données lorsque vous utilisez notre application.

Notre engagement : Teslivery est conçue pour fonctionner entièrement hors-ligne. Nous ne collectons, ne transmettons et ne partageons aucune donnée personnelle avec des tiers.

2. Données collectées

Teslivery ne collecte aucune donnée personnelle. L'application ne nécessite pas de compte utilisateur, ne demande pas d'accès à vos contacts, et ne transmet aucune information à des serveurs externes.

Les seules données générées par l'application sont :

  • Données d'inspection : Informations sur les véhicules inspectés (nom, VIN, photos, notes)
  • Photos : Images prises lors de l'inspection
  • Rapports : Documents PDF ou texte générés localement

3. Stockage des données

Toutes les données sont stockées localement sur votre appareil dans une base de données SQLite sécurisée. Aucune donnée n'est envoyée sur Internet ou sur des serveurs cloud.

Vous avez un contrôle total sur vos données :

  • Vous pouvez supprimer n'importe quelle inspection à tout moment
  • Vous pouvez désinstaller l'application pour supprimer toutes les données
  • Les photos sont stockées dans le stockage interne de l'application

4. Partage des données

Teslivery ne partage aucune donnée avec des tiers. Les rapports d'inspection que vous exportez (PDF ou texte) restent sous votre contrôle et ne sont partagés que si vous le décidez explicitement (par email, WhatsApp, etc.).

5. Autorisations demandées

L'application demande les autorisations suivantes, uniquement pour son fonctionnement :

  • Caméra : Pour prendre des photos lors de l'inspection
  • Stockage : Pour sauvegarder les photos et les rapports
  • Partage : Pour exporter les rapports vers d'autres applications

Aucune de ces autorisations n'est utilisée pour collecter ou transmettre des données.

6. Sécurité

Les données stockées localement sont protégées par le système de sécurité d'Android. Chaque application dispose de son propre espace de stockage isolé, inaccessible aux autres applications.

7. Enfants

Teslivery n'est pas destinée aux enfants de moins de 13 ans. L'application ne collecte intentionnellement aucune donnée personnelle d'enfants.

8. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité de temps à autre. Toute modification sera publiée sur cette page avec une date de mise à jour révisée.
